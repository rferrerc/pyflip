## FLIP: (Ph)ysics-based Learning for Imaging Planets

A python library implementing the FLIP framework for stellar PSF subtraction for exoplanet imaging. 

The code is currently mostly tailored for JWST/NIRCam coronagraphic imaging.

For details on the FLIP method, see our paper ([Ferrer-Chavez et al. 2026](https://www.nature.com/articles/s41586-026-11213-z)).
